# Design 

结构检查只需要检查结构吗？显然不是，我们还得用来处理各种信息的转换，类似于将三维结构进行编译一类的操作，
我们实际上是在进行某种类AST操作，同时机器决定一切，任何结构都只是简化机器本身的逻辑，将这部分逻辑统一标准化。


## 如何描述一个结构

平凡的，我们把每一个坐标都存储在一个三维矩阵，但是这样存在问题，例如门这种对象是非标准的，同时，它假设了结构是不动的，固定的，同时是方块的。

本质上，都能表现为某种`Set<Part>`类似的结构，但为了优化和后续流程，实践上我们需要定义为某种
定义和变换器这两者组合得到一个最终状态，状态可以包含任意机器需要的信息，机器成型只是最基础的
